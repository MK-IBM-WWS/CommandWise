# Журнал архитектурных решений

| ID | Решение | Основание | Ограничение |
| --- | --- | --- | --- |
| D01 | BM25 в первой версии | Требование курса; простая CPU-реализация | Чувствителен к языку и формулировке |
| D02 | Русский corpus, источники и версии | Русские вопросы/ответы, проверяемые flags | Требуется ручная сверка перевода |
| D03 | Go управляет RAG, Python выполняет search | Разделение ролей, независимые контракты | Дополнительный внутренний HTTP-вызов |
| D04 | Пять сервисов в Compose на одном сервере | Имеющееся оборудование, маленькая команда | Один физический узел отказа |
| D05 | Tailscale для команды | NAT, закрытый доступ без домашнего VPN | Используется внешняя координация/relay |
| D06 | GitHub + PR; будущие Actions/GHCR | Пользователь выбрал GitHub; единая платформа | Quotas/protection зависят от плана |
| D07 | main + короткие task branches | Три участника, частая интеграция | Требует регулярного review |
| D08 | Cookie-сессия и snapshots | Минимальный доступ и история источников | Пока нет восстановления аккаунта |
| D09 | HTML mock-prototype на CP1; React далее | Проверяемый показ без GPU/API | Не доказывает работу RAG |

Смена существенного решения фиксируется новым пунктом с причиной, влиянием на контракт и проверкой. Не считать внешнюю рекомендацию неизменяемым требованием курса.

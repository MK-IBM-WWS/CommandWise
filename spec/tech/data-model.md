# Данные PostgreSQL

Начальная миграция создаёт четыре таблицы. Миграция 00002 оставляет исторический столбец release, добавляет пустое значение по умолчанию для новых чатов.

| Таблица | Значимые поля |
| --- | --- |
| accounts | UUID, уникальный нормализованный логин, bcrypt-хеш, роль user или admin |
| sessions | UUID идентификатора JWT, аккаунт, время истечения |
| chats | UUID, аккаунт, название, дистрибутив, время создания |
| messages | UUID, порядок, чат и аккаунт, роль, текст, состояние, UUID клиентского запроса, исходный вопрос, snapshots, версия корпуса, причина окончания и флаг отмены |

Чаты удаляются вместе с сообщениями. Вызовы создания чата, удаления и постановки вопроса сериализуются блокировкой строки аккаунта. Уникальные индексы исключают второе незавершённое задание в чате и второе исполняемое задание на аккаунт. Планировщик с двумя рабочими слотами выбирает ожидающие записи по порядку поступления. Частичный ответ сохраняется по ходу генерации.

Снимок источника содержит идентификаторы, заголовки, текст, URL и метаданные применимости. Версия корпуса сохранена вместе с сообщением. JWT действует 24 часа и отзывается удалением серверной сессии.

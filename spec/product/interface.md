# Интерфейс

## Макет

Один экран чата: боковая панель с новым чатом и историей, заголовок с target, область сообщений, поле ввода и действия отправки/остановки. На узком экране панели перестраиваются без горизонтального scroll страницы. Блоки команд имеют собственный scroll.

Новый чат выбирает систему и release. В рабочей версии список поступает из `/api/v1/corpus`; в HTML-прототипе это демонстрационные варианты. Target созданного чата не редактируется.

## Сообщение помощника

Русский текст, блок команды, кнопка копирования, статус ответа и список источников. Источник открывается в modal: название, использованный фрагмент, применимость, версия и ссылка на оригинал. Поисковый score не показывается как «процент уверенности».

## Состояния

Пустая история, создание чата, ожидание, постепенный вывод, завершение, отмена, no_context, временная ошибка. Кнопки блокируются по смыслу; клавиатура Enter отправляет, Shift+Enter переносит строку. Пользователь видит сообщение об отмене и может продолжить.

## Безопасность и доступность

Текст модели не выполняется как HTML; shell-код только отображается. Ссылки на проверенные внешние источники используют http/https и безопасное открытие вкладки. Видимые labels, focus, читаемый контраст и статус для assistive tools обязательны. Автоскролл не должен мешать чтению старых сообщений в рабочей версии.

## Прототип и рабочая реализация

`prototype/index.html`, `style.css`, `app.js` — автономный прототип для точки 1. Banner постоянно сообщает «Прототип: mock-ответы, без BM25 и LLM». Он хранит демонстрационные чаты локально и не является production SPA.

`frontend/` зарезервирован для будущей реализации React + TypeScript + Vite, fetch, react-markdown, remark-gfm и CSS. Prototype не вводит новый production-стек и не требует от RAG-специалиста писать UI.

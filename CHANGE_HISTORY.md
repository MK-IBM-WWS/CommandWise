# История изменений

## Установка на Debian 13 · 20 ноября 2026

- Добавлены `install-debian.sh` для установки под Trixie и `start-debian.sh` для запуска собранных сервисов и проверки готовности API.
- Модели, первоначальная настройка администратора и запуск используют общие сценарии с Fedora. Параметры контейнеров и тома Compose совпадают.
- На Debian 13 проверены сценарии с имитацией APT, Docker и NVIDIA для новой установки, существующих пакетов Docker, повторного запуска, первого создания администратора и готовности API. Конфигурация Compose проверена штатной командой. Пробный запуск контейнеров с физической GPU требует машины с NVIDIA.

## CommandWise для Fedora · 20 ноября 2026

- Реализованы регистрация, вход и отзыв JWT-сессий, PostgreSQL-миграции и Go API. Пользователь может создать до десяти чатов с историей, источниками и отменой ответа.
- Очередь хранится в PostgreSQL, два задания могут выполняться одновременно у разных аккаунтов. UI адаптирован из прототипа команды и читает SSE.
- В отдельной панели администратора можно публиковать русскоязычный Markdown в корпус. Сохранённые источники остаются доступны после переиндексации.
- Compose запускает Go, React/Nginx, PostgreSQL, FastAPI с E5 на CPU и Qwen3.5-4B через llama.cpp CUDA. Установщик Fedora скачивает закреплённые веса и создаёт администратора.
- Обновлены внешний и внутренний OpenAPI, форматы очереди и корпуса, руководство по установке.

### Проверки

- `go vet` и `go test -race` с PostgreSQL 17.7. Проверены JWT и выход, разграничение ролей, параллельное создание чатов, лимит чатов, очередь, отмена, сохранение фрагмента ответа, SSE и сохранённые источники.
- `npm run typecheck` и `npm run build` прошли.
- Search. 16 тестов прошли, включая загрузку и перезапуск с настоящим E5. На dev-наборе из 18 вопросов рабочий Search API вернул правильную команду на первом месте для всех 16 положительных примеров и пустую выдачу для обоих отрицательных. Это результат на dev-наборе исходного проекта.
- Синтаксис shell-скриптов, валидность двух спецификаций OpenAPI и `docker compose config --quiet` проверены.
- Сквозная проверка Go, PostgreSQL, Search и llama.cpp b12464 с настоящей Qwen3.5-4B Q4_K_M на CPU. Два запроса про `grep` и `find` завершились с источниками, третий чат оставался в очереди. Два ответа заняли около 55,5 секунды на тестовом CPU.
- Публикация Markdown прошла через Go API и Search. Собранный React проверен с живым Go API в jsdom: регистрация, создание чата, SSE, выход и маршрут администратора. Chromium в тестовом окружении не смог запустить собственный процесс.
- Установка на Fedora и замер VRAM на RTX 4070 требуют хоста с видеокартой NVIDIA. В проверочном окружении модель запускалась на CPU.

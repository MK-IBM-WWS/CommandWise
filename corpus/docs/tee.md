# tee — одновременный вывод в терминал и запись в файл

## Назначение

Команда `tee` читает стандартный ввод и копирует его одновременно на экран и в один или несколько файлов.

Подходит для вопросов «как сохранить вывод команды в файл и видеть его на экране» и «как дописать лог, не прерывая вывод в терминал».

## Синтаксис

```bash
команда | tee [параметры] файл...
```

## Основные параметры

- `-a` — добавлять данные в конец файла вместо перезаписи.
- `-i` — игнорировать сигналы прерывания.

## Сохранить вывод команды и показать его

```bash
ls -l | tee files.txt
```

Показывает список файлов в терминале и одновременно записывает его в `files.txt`.

## Добавить строку в существующий файл

```bash
echo "Новая запись" | tee -a notes.txt
```

Дописывает строку в конец `notes.txt` и выводит её на экран.

## Сохранить вывод диагностики процессов

```bash
ps -ef | tee processes.txt
```

Записывает список процессов в файл и отображает его в терминале.

## Записать вывод сразу в два файла

```bash
echo "Проверка" | tee first.txt second.txt
```

Создаёт или перезаписывает два файла одинаковым содержимым и также показывает строку на экране.

## Использовать перенаправление ошибок

```bash
ls /no-such-path 2>&1 | tee errors.txt
```

В Bash объединяет поток ошибок со стандартным выводом, затем показывает и записывает сообщение об ошибке. Путь приведён как заведомо отсутствующий пример.

## Особенности

По умолчанию `tee` перезаписывает содержимое целевых файлов. Чтобы не стирать прежние данные, используй `-a`.

В отличие от оператора `>`, который обычно отправляет вывод только в файл, `tee` одновременно сохраняет вывод на экран.

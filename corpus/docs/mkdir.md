# mkdir — создание каталогов

## Назначение

Команда `mkdir` создаёт новые каталоги Linux.

Используется для организации файлов, создания папок проекта и вложенных каталогов.

## Синтаксис

```bash
mkdir [параметры] каталог
```

## Основные параметры

- `-p` — создавать необходимые родительские каталоги.
- `-v` — показывать создаваемые каталоги.
- `-m` — задавать права доступа.

## Создание каталога

```bash
mkdir documents
```

Создаёт каталог `documents` в текущей папке.

## Создание нескольких каталогов

```bash
mkdir images videos documents
```

Создаёт три каталога.

## Создание вложенных каталогов

```bash
mkdir -p project/src/tests
```

Создаёт всю необходимую структуру каталогов.

## Создание с подробным выводом

```bash
mkdir -v backup
```

Показывает информацию о создаваемом каталоге.

## Создание каталога с правами доступа

```bash
mkdir -m 700 private
```

Создаёт каталог с правами чтения, записи и входа для владельца.

## Особенности

Без параметра `-p` команда обычно сообщает об ошибке, если каталог уже существует.

Параметр `-p` позволяет не считать существующий каталог ошибкой.

## Debian

Пакет: `coreutils`. -p создаёт недостающие родительские каталоги.

```bash
mkdir -p -- demo/reports/2026
```

## Fedora

Пакет: `coreutils`. -p создаёт недостающие родительские каталоги.

```bash
mkdir -p -- demo/reports/2026
```

## Arch Linux


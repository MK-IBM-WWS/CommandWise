# grep — поиск текста в файлах

## Назначение

Команда `grep` ищет строки, соответствующие заданному шаблону.

Используется для поиска слов, ошибок в логах, строк в исходном коде и других текстовых данных.

## Синтаксис

```bash
grep [параметры] "шаблон" [файл]
```

## Основные параметры

- `-i` — игнорировать регистр букв.
- `-n` — показывать номера найденных строк.
- `-r` — рекурсивно искать в каталогах.
- `-R` — рекурсивно искать, переходя также по символическим ссылкам.
- `-v` — выводить строки, не соответствующие шаблону.
- `-c` — показывать количество совпавших строк.
- `-l` — показывать только имена файлов с совпадениями.
- `-E` — использовать расширенные регулярные выражения.
- `--include` — ограничить поиск файлами по шаблону имени.
- `--exclude-dir` — исключить каталоги из поиска.

## Поиск слова в файле

```bash
grep "error" app.log
```

Находит строки со словом `error` в файле `app.log`.

## Поиск без учёта регистра

```bash
grep -i "error" app.log
```

Находит `error`, `ERROR`, `Error` и другие варианты регистра.

## Поиск с номерами строк

```bash
grep -n "error" app.log
```

Показывает совпавшие строки и их номера.

## Рекурсивный поиск

```bash
grep -rn "error" logs/
```

Ищет текст `error` во всех подходящих файлах каталога `logs/` и его подкаталогов.

## Поиск только в Python-файлах

```bash
grep -rn --include="*.py" "import" .
```

Ищет строки с `import` в файлах `.py`.

## Исключение каталога

```bash
grep -rn --exclude-dir=".git" "TODO" .
```

Ищет `TODO`, пропуская каталог `.git`.

## Поиск строк без указанного слова

```bash
grep -v "DEBUG" app.log
```

Выводит строки, в которых нет `DEBUG`.

## Особенности

Параметры `-r` и `-R` различаются обработкой символических ссылок.

По умолчанию `grep` использует базовые регулярные выражения. Параметр `-E` включает расширенные регулярные выражения.

## Debian

Пакет: `grep`. -i игнорирует регистр, -n добавляет номера строк.

```bash
grep -in -- 'error' app.log
```

## Fedora

Пакет: `grep`. -i игнорирует регистр, -n добавляет номера строк.

```bash
grep -in -- 'error' app.log
```

## Arch Linux

Пакет: `grep`. -i игнорирует регистр, -n добавляет номера строк.

```bash

```

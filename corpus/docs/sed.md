# sed — поиск и замена текста в потоках и файлах

## Назначение

Команда `sed` — потоковый текстовый редактор. Читает строки, выполняет команды обработки и по умолчанию печатает результат в терминал.

Подходит для вопросов «как заменить слово в тексте», «как вывести определённые строки» и «как изменить текст в файле через терминал».

## Синтаксис

```bash
sed [параметры] 'выражение' [файл]
```

## Основные параметры GNU sed

- `-n` — отключить автоматический вывод обработанных строк.
- `-e` — указать одну из нескольких команд обработки.
- `-E` — использовать расширенные регулярные выражения.
- `-i` — изменять файл на месте; возможна перезапись данных.

## Заменить первое совпадение в каждой строке

```bash
sed 's/error/warning/' app.log
```

Печатает строки с заменой первого вхождения `error` на `warning` в каждой строке. Исходный файл не меняется.

## Заменить все совпадения в каждой строке

```bash
sed 's/error/warning/g' app.log
```

Печатает результат, заменяя все вхождения `error` в каждой строке.

## Вывести определённую строку

```bash
sed -n '5p' notes.txt
```

Печатает только пятую строку файла.

## Вывести диапазон строк

```bash
sed -n '2,6p' notes.txt
```

Показывает строки со второй по шестую включительно.

## Изменить файл с резервной копией

```bash
sed -i.bak 's/old/new/g' notes.txt
```

Изменяет `notes.txt` на месте и сохраняет предыдущую версию под именем `notes.txt.bak` (в GNU sed).

## Удалить пустые строки из вывода

```bash
sed '/^$/d' notes.txt
```

Выводит содержимое без пустых строк; исходный файл не изменяется.

## Особенности и безопасность

Без `-i` команда обычно не меняет исходный файл, а только печатает преобразованный текст.

Перед массовой заменой с `-i` сделай резервную копию и проверь выражение на небольшом тестовом файле. Используй одинарные кавычки в Bash для защиты выражения от оболочки.

# sort — сортировка текстовых данных

## Назначение

Команда `sort` сортирует строки текстового файла.

Позволяет упорядочивать имена, числа, списки и другие текстовые данные.

## Синтаксис

```bash
sort [параметры] [файл]
```

## Параметры

- `-n` — числовая сортировка.
- `-r` — сортировка в обратном порядке.
- `-u` — удаление повторяющихся строк при сортировке.
- `-k` — сортировка по указанному полю.
- `-h` — сортировка чисел с суффиксами размеров.
- `-o` — записать результат в файл.

## Обычная сортировка

```bash
sort names.txt
```

Выводит строки в отсортированном порядке.

## Сортировка чисел

```bash
sort -n numbers.txt
```

Сортирует строки по числовому значению, а не только как текст.

## Сортировка по убыванию

```bash
sort -nr numbers.txt
```

Сортирует числа в обратном порядке — от большего к меньшему.

## Удаление повторов

```bash
sort -u names.txt
```

Сортирует строки и выводит уникальные значения.

## Сохранение отсортированных строк

```bash
sort names.txt -o sorted.txt
```

Записывает результат в `sorted.txt`.

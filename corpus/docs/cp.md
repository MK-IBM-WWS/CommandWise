# cp — копирование файлов и каталогов

## Назначение

Команда `cp` копирует файлы и каталоги.
Позволяет создать копию файла, сделать резервную копию или скопировать целую папку.

## Синтаксис

```bash
cp [параметры] источник назначение
```

## Основные параметры

- `-i` — запросить подтверждение перед перезаписью.
- `-R` — рекурсивное копирование каталога.
- `-a` — архивное копирование с сохранением структуры и атрибутов, насколько возможно.
- `-v` — показать выполняемые операции.
- `-p` — сохранить основные атрибуты файла, насколько позволяют права и файловая система.

## Копирование файла

```bash
cp file.txt copy.txt
```

Создаёт копию `file.txt` с именем `copy.txt`.

## Резервная копия файла

```bash
cp report.txt report.backup.txt
```

Создаёт резервную копию документа.

## Копирование в другую папку

```bash
cp report.txt documents/
```

Копирует файл в существующий каталог `documents`.

## Рекурсивное копирование каталога

```bash
cp -R project/ project-copy/
```

Создаёт копию каталога вместе с содержимым.

## Копирование с подтверждением

```bash
cp -i report.txt backup.txt
```

Запрашивает подтверждение, если целевой файл уже существует и будет перезаписан.

## Особенности

Обычная команда `cp` не удаляет исходный файл.

Перед копированием проверяй целевой путь: существующий файл может быть перезаписан.

## Debian

Пакет: `coreutils`. Флаг -i запрашивает подтверждение перед перезаписью.

```bash
cp -i -- report.txt report-copy.txt
```

## Fedora

Пакет: `coreutils`. Флаг -i запрашивает подтверждение перед перезаписью.

```bash
cp -i -- report.txt report-copy.txt
```

## Arch Linux

Пакет: `coreutils`. Флаг -i запрашивает подтверждение перед перезаписью.

```bash
cp -i -- report.txt report-copy.txt
```


# tar — работа с архивами

## Назначение

Команда `tar` используется для создания, просмотра и распаковки архивов.

Позволяет объединять файлы и каталоги в один архив.

В сочетании с gzip позволяет создавать сжатые архивы `.tar.gz`.

## Синтаксис

```bash
tar [параметры] [архив] [файлы]
```

## Основные параметры

- `-c` — создать архив.
- `-x` — извлечь файлы из архива.
- `-t` — показать содержимое архива.
- `-v` — подробный вывод.
- `-f` — указать имя файла архива.
- `-z` — использовать gzip.
- `-j` — использовать bzip2.
- `-J` — использовать xz.
- `-C` — перейти в указанный каталог при выполнении операции.

## Создать обычный архив

```bash
tar -cf archive.tar documents/
```

Создаёт архив `archive.tar`, содержащий каталог `documents/`.

Исходный каталог при этом сохраняется.

## Создать сжатый архив

```bash
tar -czf archive.tar.gz documents/
```

Создаёт архив с gzip-сжатием.

## Посмотреть содержимое архива

```bash
tar -tf archive.tar
```

Показывает список файлов в архиве.

## Посмотреть содержимое сжатого архива

```bash
tar -tzf archive.tar.gz
```

Показывает содержимое gzip-архива без извлечения.

## Распаковать обычный архив

```bash
tar -xf archive.tar
```

Извлекает содержимое архива в текущий каталог.

## Распаковать gzip-архив

```bash
tar -xzf archive.tar.gz
```

Распаковывает архив с gzip-сжатием.

## Распаковать в определённую папку

```bash
mkdir -p restored
tar -xzf archive.tar.gz -C restored/
```

Создаёт каталог `restored`, затем распаковывает архив в него.

## Создать архив с подробным выводом

```bash
tar -czvf backup.tar.gz documents/
```

Создаёт gzip-архив и показывает обрабатываемые файлы.

## Особенности и безопасность

Для работы примеров каталог `documents/` должен существовать.

Архивы `.tar` не обязательно сжаты. Параметр `-z` включает gzip.

При извлечении файлы могут перезаписываться. Перед распаковкой неизвестного архива рекомендуется посмотреть его содержимое и использовать отдельный тестовый каталог.

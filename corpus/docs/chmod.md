
# chmod — изменение прав доступа

## Назначение

Команда `chmod` изменяет права доступа к файлам и каталогам Linux.

Позволяет разрешить или запретить чтение, запись и выполнение.

## Синтаксис

```bash
chmod [параметры] режим файл
```

## Типы прав

- `r` — чтение (read).
- `w` — запись (write).
- `x` — выполнение (execute).

## Категории пользователей

- `u` — владелец файла.
- `g` — группа файла.
- `o` — остальные пользователи.
- `a` — все категории.

## Числовая запись прав

Права можно задавать числами:

- `4` — чтение.
- `2` — запись.
- `1` — выполнение.

Числа складываются.

Например:

- `7` = 4 + 2 + 1 — чтение, запись, выполнение.
- `6` = 4 + 2 — чтение и запись.
- `5` = 4 + 1 — чтение и выполнение.
- `0` — нет разрешений.

Три цифры обозначают права владельца, группы и остальных.

## Права 755

```bash
chmod 755 script.sh
```

Владелец может читать, изменять и выполнять файл.

Группа и остальные пользователи могут читать и выполнять.

## Права 644

```bash
chmod 644 document.txt
```

Владелец может читать и изменять файл.

Остальные могут только читать.

## Добавить право выполнения

```bash
chmod u+x script.sh
```

Добавляет владельцу право выполнения файла.

Эта команда позволяет сделать файл исполняемым, то есть разрешить его запуск как программы, если содержимое файла допускает выполнение.

Для всех категорий пользователей можно использовать:

```bash
chmod a+x script.sh
```

Однако предоставлять право выполнения всем пользователям нужно только при необходимости.

## Запретить запись остальным

```bash
chmod o-w document.txt
```

Убирает право записи у остальных пользователей.

## Рекурсивное изменение

```bash
chmod -R u+rwX project/
```

Рекурсивно добавляет владельцу права чтения и записи.

Символ `X` добавляет выполнение для каталогов и для файлов, у которых уже установлен хотя бы один бит выполнения.

## Основные параметры

- `-R` — рекурсивное изменение прав.
- `-v` — подробный вывод операций.
- `-c` — выводить информацию только при изменении.
- `--reference` — скопировать права другого файла.

## Особенности и безопасность

Для изменения прав обычно нужно быть владельцем файла или обладать соответствующими полномочиями.

Рекурсивный `chmod` может изменить права большого числа файлов.

Не рекомендуется без необходимости задавать права `777`, особенно в общедоступных каталогах.

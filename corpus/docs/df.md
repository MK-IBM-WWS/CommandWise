# df — информация о дисковом пространстве

## Назначение

Команда `df` показывает свободное и занятое место на смонтированных файловых системах Linux.

Позволяет узнать, сколько места осталось на диске или разделе.

## Синтаксис

```bash
df [параметры] [путь]
```

## Параметры

- `-h` — показать размеры в удобных единицах.
- `-T` — показать тип файловой системы.
- `-i` — показать использование inode.
- `-a` — включить также специальные файловые системы.
- `-l` — отображать только локальные файловые системы.

## Свободное место на дисках

```bash
df -h
```

Показывает общий размер, занятое и доступное место смонтированных файловых систем.

## Информация о корневом разделе

```bash
df -h /
```

Показывает информацию о файловой системе, содержащей корневой каталог.

## Типы файловых систем

```bash
df -Th
```

Показывает использование пространства и типы файловых систем.

## Проверка inode

```bash
df -i
```

Показывает количество использованных и свободных inode.

## Особенности

`df` показывает использование файловой системы целиком.

Если нужно определить размер конкретного каталога, используй `du`.

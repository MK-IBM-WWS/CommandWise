# ln — создание символических и жёстких ссылок

## Назначение

Команда `ln` создаёт ссылки на файлы или каталоги. Символическая ссылка ведёт на путь, а жёсткая ссылка — на тот же файловый объект.

Подходит для вопросов «как создать симлинк», «как сделать ссылку на файл» и «как связать два имени с одним файлом».

## Синтаксис

```bash
ln [параметры] цель имя_ссылки
```

## Основные параметры

- `-s` — создать символическую ссылку.
- `-f` — удалить существующее целевое имя ссылки при необходимости, если операция допустима.
- `-i` — запросить подтверждение перед заменой существующего имени.
- `-v` — вывести информацию о создании ссылок.

## Создание символической ссылки на файл

```bash
ln -s report.txt report-link.txt
```

Создаёт символическую ссылку `report-link.txt`, указывающую на `report.txt` в том же каталоге.

## Создание ссылки на каталог

```bash
ln -s /var/log logs-link
```

Создаёт ссылку `logs-link`, ведущую к каталогу `/var/log`.

## Создание жёсткой ссылки

```bash
ln report.txt report-hard.txt
```

Создаёт ещё одно имя для того же файла; изменение содержимого через любое из имён отражается на общем файле.

## Создание ссылки с подробным выводом

```bash
ln -sv report.txt report-link.txt
```

Показывает сообщение о создаваемой символической ссылке.

## Проверка символической ссылки

```bash
ls -l report-link.txt
```

Показывает ссылку и путь, на который она указывает.

## Особенности

Символическая ссылка может стать нерабочей, если цель перемещена или удалена. Относительная цель вычисляется относительно каталога самой ссылки.

Жёсткие ссылки обычно нельзя создавать на каталоги и между разными файловыми системами.

Удаление самой символической ссылки с помощью `rm` не удаляет её цель.

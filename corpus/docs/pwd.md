# pwd — показать текущий каталог

## Назначение

Команда `pwd` печатает полный путь к текущему рабочему каталогу терминала Linux.

Подходит для вопросов «где я нахожусь», «как узнать текущую папку» и «как вывести полный путь каталога».

## Синтаксис

```bash
pwd [параметры]
```

## Основные параметры Bash

- `-L` — показать логический путь, который может сохранять компоненты символических ссылок.
- `-P` — показать физический путь с разрешёнными символическими ссылками.

## Показать текущий каталог

```bash
pwd
```

Печатает текущий путь, например `/home/student/projects`.

## Показать физический путь

```bash
pwd -P
```

Выводит путь к фактическому каталогу без символических ссылок в компонентах пути.

## Показать логический путь

```bash
pwd -L
```

Выводит путь с сохранением логических компонентов, когда они доступны.

## Проверить путь после перехода

```bash
cd /var/log
pwd
```

Сначала выполняется переход в каталог `/var/log`, затем печатается его абсолютный путь.

## Особенности

В Bash `pwd` обычно выполняется как встроенная команда оболочки; отдельная утилита `/bin/pwd` также может присутствовать и иметь собственные параметры по умолчанию.

`pwd` не показывает список файлов. Для просмотра содержимого каталога используется `ls`.

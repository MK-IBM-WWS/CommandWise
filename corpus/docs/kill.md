# kill — отправка сигналов процессам

## Назначение

Команда `kill` отправляет сигнал указанному процессу Linux.

Обычно используется для запроса завершения процесса.

Для работы необходимо знать PID процесса и иметь соответствующие права.

## Синтаксис

```bash
kill [сигнал] PID
```

## Сигналы

- `SIGTERM` — запросить завершение процесса.
- `SIGKILL` — принудительно завершить процесс.
- `SIGHUP` — сигнал, который приложения могут использовать для перечитывания настроек.
- `SIGSTOP` — приостановить выполнение.
- `SIGCONT` — продолжить выполнение.

## Обычное завершение процесса

```bash
kill -TERM 1234
```

Отправляет процессу с PID 1234 сигнал SIGTERM.

Процесс может обработать этот сигнал и корректно завершить работу.

## Принудительное завершение

```bash
kill -KILL 1234
```

Отправляет SIGKILL.

Это крайний вариант, поскольку процесс не может обработать этот сигнал и выполнить обычное завершение.

## Посмотреть доступные сигналы

```bash
kill -l
```

Показывает список имён сигналов.

## Связь с командой ps

Сначала можно посмотреть PID:

```bash
ps -ef
```

Затем отправить сигнал выбранному процессу.

## Особенности и безопасность

Не завершай системные или чужие процессы без необходимости.

PID в примерах условный. Перед использованием нужно проверить настоящий идентификатор процесса.

Во многих командных оболочках `kill` является встроенной командой. Набор дополнительных параметров может отличаться от отдельной утилиты `/usr/bin/kill`.

## Debian

Пакет: `procps`. Для определения реализации выполни `type -a kill`. Подставь PID своего процесса. Оболочка часто использует встроенный kill. SIGTERM даёт процессу возможность завершиться штатно.

```bash
kill -TERM 1234
```

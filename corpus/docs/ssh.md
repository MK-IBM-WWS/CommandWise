# ssh — безопасное удалённое подключение

## Назначение

Команда `ssh` позволяет подключаться к удалённому компьютеру по защищённому соединению.

Используется для удалённого администрирования Linux-серверов и выполнения команд.

## Синтаксис

```bash
ssh [параметры] пользователь@сервер
```

## Параметры

- `-p PORT` — указать порт подключения.
- `-i FILE` — выбрать файл ключа для аутентификации.
- `-v` — подробные диагностические сообщения.
- `-4` — использовать IPv4.
- `-6` — использовать IPv6.

## Подключение к серверу

```bash
ssh student@server.example.com
```

Подключается к удалённому серверу под пользователем `student`.

Имя сервера в примере условное.

## Подключение по IP-адресу

```bash
ssh student@192.0.2.10
```

Показывает синтаксис подключения по IP.

Использован специальный адрес, предназначенный для документационных примеров.

## Подключение через другой порт

```bash
ssh -p 2222 student@server.example.com
```

Использует порт 2222 вместо стандартного 22.

## Подключение по SSH-ключу

```bash
ssh -i ~/.ssh/id_ed25519 student@server.example.com
```

Использует указанный файл закрытого ключа для аутентификации.

## Выполнение удалённой команды

```bash
ssh student@server.example.com "hostname"
```

Запрашивает выполнение `hostname` на удалённом сервере.

## Безопасность

При первом подключении SSH предлагает проверить подлинность ключа сервера.

Отпечаток ключа нужно сверять с достоверным источником.

Не передавай закрытый SSH-ключ другим пользователям и не сохраняй его в Git.

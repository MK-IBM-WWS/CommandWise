# ps — просмотр запущенных процессов

## Назначение

Команда `ps` показывает информацию о процессах Linux.

Позволяет узнать PID процесса, пользователя, состояние и выполняемую программу.

## Синтаксис

```bash
ps [параметры]
```

## Понятия

PID — числовой идентификатор процесса.

PPID — идентификатор родительского процесса.

Процесс — выполняющаяся программа.

## Параметры и режимы

- `-e` — показать все процессы.
- `-f` — подробный формат вывода.
- `-p PID` — выбрать процесс по идентификатору.
- `-o` — задать нужные столбцы.
- `aux` — распространённый формат BSD для просмотра процессов.

## Просмотр текущих процессов

```bash
ps
```

Показывает процессы, выбранные по умолчанию для текущего терминала и пользователя.

## Все процессы Linux

```bash
ps -ef
```

Показывает список всех процессов с подробной информацией.

## Список с использованием CPU и памяти

```bash
ps aux
```

Показывает процессы в распространённом BSD-формате, включая показатели использования CPU и памяти.

## Информация о конкретном процессе

```bash
ps -p 1234 -o pid,ppid,cmd
```

Показывает PID, PPID и команду процесса с идентификатором 1234, если он существует.

## Особенности

`ps` показывает состояние процессов на момент выполнения команды.

Для непрерывного наблюдения обычно используют `top` или другие средства мониторинга.

Синтаксис `ps aux` отличается от `ps -aux`: в Linux смешение BSD и UNIX-форматов может менять смысл параметров.

## Debian

Пакет: `procps`. -e выбирает все процессы, -o задаёт поля вывода.

```bash
ps -eo pid,ppid,user,comm
```

## Fedora

Пакет: `procps-ng`. -e выбирает все процессы, -o задаёт поля вывода.

```bash
ps -eo pid,ppid,user,comm
```

## Arch Linux

Пакет: `procps-ng`. -e выбирает все процессы, -o задаёт поля вывода.

```bash
ps -eo pid,ppid,user,comm
```

# less — постраничный просмотр текстовых файлов

## Назначение

Команда `less` открывает файл для удобного постраничного чтения без редактирования. Подходит для больших логов, документации и длинных текстовых файлов.

## Синтаксис

```bash
less [параметры] [файл]
```

## Основные параметры

- `-N` — показывать номера строк.
- `-S` — не переносить длинные строки автоматически.
- `-F` — завершить просмотр, если содержимое целиком помещается на одном экране.

## Открыть большой текстовый файл

```bash
less app.log
```

Открывает постраничный просмотр лога.

## Просмотреть файл с номерами строк

```bash
less -N config.txt
```

Отображает номера строк рядом с текстом.

## Просмотреть длинные строки без переноса

```bash
less -S data.txt
```

Не переносит длинные строки. Для просмотра скрытой части используй горизонтальную прокрутку.

## Найти слово в открытом файле

Во время работы `less` набери `/error` и нажми `Enter`. Клавиша `n` повторит поиск вперёд, `N` — в обратном направлении.

## Перемещение по файлу

`Space` — следующая страница; `b` — предыдущая страница; стрелки — построчная прокрутка; `g` — начало файла; `G` — конец файла.

## Выйти из просмотра

Нажми `q`, чтобы завершить `less` и вернуться в командную строку.

## Просмотр вывода другой команды

```bash
ps -ef | less
```

Позволяет постранично читать длинный список процессов.

## Особенности

`less` предназначена для просмотра, а не редактирования. Для изменения содержимого можно использовать `nano`.

На минимальных установках программа может отсутствовать.

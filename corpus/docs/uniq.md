# uniq — обработка одинаковых соседних строк

## Назначение

Команда `uniq` удаляет или подсчитывает соседние повторяющиеся строки.

Используется при обработке логов, списков и текстовых данных.

## Синтаксис

```bash
uniq [параметры] [файл]
```

## Параметры

- `-c` — показать количество повторений.
- `-d` — вывести только повторяющиеся группы строк.
- `-u` — вывести только строки, встретившиеся в группе один раз.
- `-i` — игнорировать регистр при сравнении.

## Удаление соседних повторов

```bash
uniq names.txt
```

Удаляет подряд идущие одинаковые строки.

## Удаление всех одинаковых строк из списка

```bash
sort names.txt | uniq
```

Сначала группирует одинаковые строки сортировкой, затем оставляет по одному экземпляру.

## Подсчёт повторений

```bash
sort names.txt | uniq -c
```

Показывает, сколько раз встретилась каждая строка.

## Только повторяющиеся значения

```bash
sort names.txt | uniq -d
```

Выводит значения, которые встречаются больше одного раза.

## Важная особенность

`uniq` не удаляет все повторы в произвольном порядке строк.

Она сравнивает только соседние строки, поэтому часто используется вместе с `sort`.

## Debian

Пакет: `coreutils`. uniq объединяет соседние одинаковые строки, поэтому сначала их сортируют.

```bash
sort -- names.txt | uniq -c
```

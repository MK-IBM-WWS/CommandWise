# touch — создание пустых файлов и обновление времени изменения

## Назначение

Команда `touch` создаёт новый пустой файл, если такого файла ещё нет, либо обновляет временные метки уже существующего файла.

Подходит для вопросов «как создать файл в Linux», «как быстро сделать пустой файл» и «как изменить дату изменения файла».

## Синтаксис

```bash
touch [параметры] файл...
```

## Основные параметры

- `-c` (`--no-create`) — не создавать файл, если он отсутствует.
- `-a` — изменять только время последнего доступа.
- `-m` — изменять только время последнего изменения содержимого.
- `-d 'дата'` — установить время из указанной даты.
- `-r файл` — взять временные метки из другого файла.

## Создание пустого файла

```bash
touch notes.txt
```

Создаёт пустой файл `notes.txt` в текущем каталоге, если его ещё нет. **Это один из самых простых способов создать файл в терминале Linux.**

## Создание нескольких файлов

```bash
touch first.txt second.txt third.txt
```

Создаёт три пустых файла, если они отсутствуют. Уже существующие файлы не очищаются.

## Создание файла в папке

```bash
touch documents/report.txt
```

Создаёт файл в каталоге `documents`. Каталог должен уже существовать; при необходимости сначала используй `mkdir -p documents`.

## Обновление времени изменения

```bash
touch -m report.txt
```

Обновляет время последнего изменения файла, а его содержимое не меняет.

## Не создавать отсутствующий файл

```bash
touch -c notes.txt
```

Обновляет время существующего файла, но ничего не создаёт, если файла нет.

## Изменение времени по образцу

```bash
touch -r reference.txt result.txt
```

Копирует временные метки из `reference.txt` в `result.txt`. Если `result.txt` отсутствует, он будет создан.

## Особенности

`touch` не предназначен для редактирования текста. Для создания файла с содержимым используй `nano`, перенаправление вывода `>` или другие редакторы.

Если файл уже существует, `touch` не удаляет его данные. Изменяются временные метки.

# find — поиск файлов и каталогов

## Назначение

Команда `find` ищет файлы и каталоги по заданным условиям: имени, типу, размеру, времени изменения и другим признакам. Поиск выполняется в указанном каталоге и его подкаталогах.

## Синтаксис

```bash
find [начальный_каталог] [условия_поиска] [действие]
```

- `.` означает текущий каталог.
- Если начальный каталог не указан, GNU `find` начинает поиск с `.`.
- Без явного действия `find` обычно выводит пути найденных объектов.

## Основные условия

- `-name 'шаблон'` — поиск по имени с учётом регистра.
- `-iname 'шаблон'` — поиск по имени без учёта регистра.
- `-type f` — только обычные файлы.
- `-type d` — только каталоги.
- `-size +100M` — размер больше 100 единиц по 1 МиБ с учётом правил округления `find`.
- `-size -10M` — размер меньше 10 единиц по 1 МиБ с учётом округления.
- `-mtime -7` — файлы, изменённые менее 7 суток назад (время оценивается в 24-часовых интервалах с округлением).
- `-maxdepth 1` — ограничить поиск одним уровнем (GNU-опция).
- `-print` — вывести путь каждого найденного объекта.

## Примеры использования

### 1. Найти все объекты в текущем каталоге и подкаталогах

```bash
find .
```

Выводит пути файлов и каталогов начиная с текущего каталога.

### 2. Найти все TXT-файлы

```bash
find . -type f -name '*.txt'
```

Ищет обычные файлы, имена которых оканчиваются на `.txt`. Кавычки не дают оболочке преждевременно раскрыть `*`.

### 3. Найти файл без учёта регистра имени

```bash
find . -type f -iname 'readme*'
```

Найдёт, например, `README.md`, `readme.txt` или `Readme-old`.

### 4. Найти большие файлы

```bash
find . -type f -size +100M
```

Ищет обычные файлы, размер которых превышает 100 МиБ при оценке `find` в единицах по 1 МиБ. Для строгого сравнения с числом байтов используй суффикс `c`: `-size +104857600c`.

### 5. Найти каталоги с названием logs

```bash
find . -type d -name 'logs'
```

Находит каталоги с именем `logs`.

### 6. Найти недавно изменённые файлы

```bash
find . -type f -mtime -7
```

Выводит обычные файлы, изменённые менее семи суток назад.

### 7. Найти файлы только в текущем каталоге

```bash
find . -maxdepth 1 -type f
```

Выводит обычные файлы без обхода более глубоких подкаталогов.

## Важные особенности

- Параметры имеют точное написание: `-name` и `-iname` выполняют разные проверки.
- Маски вроде `*.txt` заключай в кавычки, чтобы их обрабатывала `find`, а не командная оболочка.
- Суффикс `M` у `-size` означает МиБ (1 048 576 байт), а не десятичный мегабайт. Размеры для этого условия округляются вверх до выбранной единицы.
- Примеры только ищут и выводят имена. Они не удаляют и не изменяют файлы.

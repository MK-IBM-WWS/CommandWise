# cat — вывод содержимого файлов

## Назначение

Команда `cat` выводит содержимое файлов в терминал.

Используется для просмотра небольших текстовых файлов и объединения их содержимого.

## Синтаксис

```bash
cat [параметры] [файл]
```

## Основные параметры

- `-n` — нумеровать все выводимые строки.
- `-b` — нумеровать только непустые строки.
- `-s` — объединять последовательности пустых строк.
- `-A` — показывать непечатаемые символы, табуляции и окончания строк.

## Просмотр файла

```bash
cat notes.txt
```

Выводит содержимое файла `notes.txt`.

## Просмотр с номерами строк

```bash
cat -n notes.txt
```

Выводит текст с номерами строк.

## Нумерация непустых строк

```bash
cat -b notes.txt
```

Нумерует только непустые строки.

## Просмотр нескольких файлов

```bash
cat first.txt second.txt
```

Последовательно выводит содержимое двух файлов.

## Объединение файлов

```bash
cat first.txt second.txt > combined.txt
```

Записывает содержимое двух файлов в `combined.txt`.

Если `combined.txt` уже существует, его прежнее содержимое будет заменено.

## Особенности

Команда `cat` не является текстовым редактором.

При работе с большими файлами вывод может быть неудобным.

## Debian

Пакет: `coreutils`. Для сквозной нумерации строк используй -n.

```bash
cat notes.txt
```

## Fedora

Пакет: `coreutils`. Для сквозной нумерации строк используй -n.

```bash
cat notes.txt
```

## Arch Linux

Пакет: `coreutils`. Для сквозной нумерации строк используй -n.

```bash
cat notes.txt
```

# du — определение занятого места

## Назначение

Команда `du` показывает, сколько дискового пространства занимают файлы и каталоги.

Используется для поиска больших папок и анализа использования диска.

## Синтаксис

```bash
du [параметры] [путь]
```

## Параметры

- `-h` — удобные единицы измерения.
- `-s` — вывести только общий размер указанного объекта.
- `-a` — показывать также файлы.
- `-c` — выводить общий итог.
- `--max-depth=N` — ограничить глубину отображения каталогов.

## Размер текущего каталога

```bash
du -sh .
```

Показывает суммарный объём дискового пространства, занимаемый текущим каталогом.

## Размер указанной папки

```bash
du -sh documents/
```

Показывает размер каталога `documents`.

## Размер подкаталогов

```bash
du -h --max-depth=1 .
```

Показывает использование диска текущим каталогом и его непосредственными подкаталогами.

## Размер всех файлов и каталогов

```bash
du -ah documents/
```

Показывает занятое место, включая отдельные файлы.

## Особенности

`du` измеряет использование дискового пространства, которое может отличаться от логического размера файлов.

Для проверки свободного места на файловых системах используется другая команда — `df`.

# nano — создание и редактирование текстовых файлов

## Назначение

`nano` — консольный текстовый редактор. Позволяет создать текстовый файл, изменить конфигурацию и сохранить изменения прямо из терминала Linux.

Подходит для вопросов «как создать текстовый файл», «как изменить файл в терминале» и «как сохранить файл в nano».

## Синтаксис

```bash
nano [параметры] [файл]
```

## Основные параметры

- `-l` — показывать номера строк.
- `-B` — при сохранении создавать резервную копию прежней версии файла.
- `+СТРОКА файл` — открыть файл и перейти к указанной строке (например, `+20`).

## Создание нового текстового файла

```bash
nano notes.txt
```

Открывает редактор. Если файла ещё нет, можно ввести текст и создать файл при сохранении. **Сам запуск `nano` ещё не сохраняет новый файл на диск.**

## Сохранение файла

После ввода текста нажми `Ctrl+O`, затем `Enter` для подтверждения имени файла. Это записывает содержимое на диск.

## Выход из редактора

Нажми `Ctrl+X`. Если есть несохранённые изменения, редактор предложит сохранить их или отказаться от них.

## Редактирование существующего файла

```bash
nano config.txt
```

Открывает существующий `config.txt` для просмотра и правки, если хватает прав доступа.

## Просмотр номеров строк

```bash
nano -l config.txt
```

Показывает номера строк слева от текста — удобно для редактирования конфигураций.

## Создание резервной копии при сохранении

```bash
nano -B config.txt
```

При сохранении изменённого файла может быть создана резервная копия прежней версии. Проверяй, куда редактор сохраняет резервные файлы.

## Поиск текста внутри файла

В традиционных раскладках nano для поиска можно использовать `Ctrl+W`; актуальные комбинации клавиш зависят от версии и настройки редактора и отображаются в подсказке внизу экрана.

## Особенности

`nano` — отдельная программа, а не встроенная команда Bash. Она может быть не установлена в минимальной системе.

Для создания именно пустого файла без редактирования используй `touch`.

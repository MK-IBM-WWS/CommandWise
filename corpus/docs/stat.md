# stat — подробная информация о файле или каталоге

## Назначение

Команда `stat` показывает свойства файла: размер, права доступа, владельца, временные метки, число жёстких ссылок и другую информацию.

Используется, когда `ls -l` не хватает для диагностики файла.

## Синтаксис

```bash
stat [параметры] файл
```

## Основные параметры GNU stat

- `-c ФОРМАТ` — вывести выбранные свойства в заданном формате.
- `-L` — следовать по символической ссылке и показывать данные её цели.
- `-f` — показать информацию о файловой системе, а не о файле.
- `-t` — вывести данные в компактном формате.

## Показать полную информацию о файле

```bash
stat report.txt
```

Показывает размер, права, владельца и времена изменения файла.

## Узнать размер файла в байтах

```bash
stat -c '%s' report.txt
```

Печатает логический размер файла в байтах.

## Узнать права доступа файла

```bash
stat -c '%A %a' report.txt
```

Показывает права в символьном и восьмеричном представлении.

## Узнать владельца и группу

```bash
stat -c '%U %G' report.txt
```

Показывает владельца и группу файла.

## Время последнего изменения

```bash
stat -c '%y' report.txt
```

Показывает временную метку последнего изменения содержимого.

## Информация о файловой системе

```bash
stat -f .
```

Показывает свойства файловой системы, содержащей текущий каталог.

## Особенности

`stat` только читает метаданные и не изменяет файл. Для обновления времени изменения используют `touch`.

Точные доступные поля форматирования зависят от реализации; здесь приведены форматы GNU Coreutils.

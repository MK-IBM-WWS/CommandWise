# cd — переход между каталогами

## Назначение

Команда `cd` меняет текущий рабочий каталог командной оболочки Bash.

Используется для перехода в папки, возвращения в домашний каталог и перемещения по файловой системе Linux.

## Синтаксис

```bash
cd [каталог]
```

## Основные варианты

- `cd` — перейти в домашний каталог.
- `cd ~` — перейти в домашний каталог пользователя.
- `cd ..` — перейти на один уровень вверх.
- `cd -` — вернуться в предыдущий рабочий каталог.
- `cd -P каталог` — использовать физический путь с разрешением символических ссылок.

## Переход в каталог

```bash
cd documents
```

Переходит в существующую папку `documents`, расположенную внутри текущего каталога.

## Переход на уровень выше

```bash
cd ..
```

Переходит в родительский каталог.

## Возврат в домашний каталог

```bash
cd ~
```

Переходит в домашнюю папку текущего пользователя.

## Возврат в предыдущий каталог

```bash
cd -
```

Возвращает в каталог, где пользователь находился перед последним переходом.

## Переход по абсолютному пути

```bash
cd /var/log
```

Переходит в каталог `/var/log` при наличии доступа.

## Каталог с пробелом в названии

```bash
cd "My Documents"
```

Кавычки позволяют обработать путь с пробелами как один аргумент.

## Особенности

`cd` — встроенная команда Bash: изменение каталога должно происходить внутри текущей оболочки, поэтому отдельная внешняя программа не могла бы изменить каталог родительского терминала.

Команда `cd` не создаёт каталоги. Для создания используй `mkdir`, а для отображения текущего пути — `pwd`.

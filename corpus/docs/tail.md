# tail — просмотр конца файла

## Назначение

Команда `tail` показывает последние строки файла.

Используется для просмотра последних записей логов и наблюдения за новыми сообщениями.

## Синтаксис

```bash
tail [параметры] [файл]
```

## Параметры

- `-n N` — вывести последние N строк.
- `-c N` — вывести последние N байтов.
- `-f` — следить за добавлением данных в файл.
- `-F` — следить за именем файла и пытаться открыть его повторно после замены.

## Последние 10 строк

```bash
tail app.log
```

Показывает последние десять строк.

## Последние 50 строк

```bash
tail -n 50 app.log
```

Выводит последние пятьдесят строк файла.

## Наблюдение за логом в реальном времени

```bash
tail -f app.log
```

Показывает последние строки и продолжает выводить новые данные по мере их появления.

Для остановки наблюдения нажми Ctrl+C.

## Наблюдение с учётом ротации логов

```bash
tail -F app.log
```

Продолжает попытки отслеживать файл по имени, даже если он был заменён или временно отсутствует.

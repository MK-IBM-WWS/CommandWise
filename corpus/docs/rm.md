# rm — удаление файлов и каталогов

## Назначение

Команда `rm` удаляет файлы и каталоги Linux.

Используется для удаления ненужных данных и очистки тестовых папок.

## Синтаксис

```bash
rm [параметры] файл
```

## Основные параметры

- `-i` — спрашивать подтверждение удаления.
- `-I` — запрашивать одно подтверждение для опасных групповых или рекурсивных операций.
- `-r` — рекурсивно удалять каталоги.
- `-f` — игнорировать несуществующие файлы и не запрашивать подтверждение.
- `-v` — показывать удаляемые файлы.

## Удаление файла

```bash
rm -- example.txt
```

Удаляет файл `example.txt`.

## Удаление с подтверждением

```bash
rm -i -- example.txt
```

Запрашивает подтверждение перед удалением файла.

## Рекурсивное удаление каталога

```bash
rm -r -- test-directory/
```

Удаляет каталог `test-directory` вместе с содержимым.

Использовать только для каталога, данные которого действительно не нужны.

## Подробный вывод

```bash
rm -v -- old.txt
```

Показывает информацию об удалении файла.

## Особенности и безопасность

Команда `rm` не перемещает файлы в корзину.

Удаление может приводить к необратимой потере данных.

Особенно опасно сочетание `-r` и `-f`, поскольку оно позволяет удалять целые деревья каталогов без подтверждения.

В примерах используй только временные тестовые файлы и каталоги.

## Debian

Пакет: `coreutils`. Используй на временном файле. -i требует подтверждения.

```bash
rm -i -- ./draft.tmp
```

## Fedora

Пакет: `coreutils`. Используй на временном файле. -i требует подтверждения.

```bash
rm -i -- ./draft.tmp
```

## Arch Linux

Пакет: `coreutils`. Используй на временном файле. -i требует подтверждения.

```bash
rm -i -- ./draft.tmp
```

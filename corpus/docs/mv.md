# mv — перемещение и переименование файлов

## Назначение

Команда `mv` перемещает или переименовывает файлы и каталоги.

В отличие от `cp`, при успешном перемещении исходное расположение файла перестаёт существовать.

## Синтаксис

```bash
mv [параметры] источник назначение
```

## Основные параметры

- `-i` — подтверждение перед перезаписью.
- `-v` — подробный вывод выполняемых операций.
- `-b` — создавать резервную копию заменяемого файла.
- `-n` — не заменять существующий целевой файл; особенности статуса завершения зависят от версии.

## Переименование файла

```bash
mv old.txt new.txt
```

Меняет имя файла.

## Перемещение файла

```bash
mv report.txt documents/
```

Перемещает файл в существующий каталог `documents`.

## Переименование каталога

```bash
mv old-folder new-folder
```

Переименовывает каталог.

## Перемещение с подтверждением

```bash
mv -i document.txt archive/
```

Спрашивает подтверждение, если возникнет необходимость заменить существующий файл.

## Подробный вывод

```bash
mv -v old.txt new.txt
```

Показывает выполняемую операцию.

## Особенности

Если источник и назначение находятся на разных файловых системах, перемещение может потребовать копирования данных и удаления исходного файла.

Перед выполнением проверь, что не перезаписываешь важные данные.

## Debian

Пакет: `coreutils`. -i запрашивает подтверждение перед заменой существующей цели.

```bash
mv -i -- report.txt report-old.txt
```

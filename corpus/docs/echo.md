# echo — вывод текста и запись строк в файл

## Назначение

Команда `echo` выводит переданные аргументы в терминал или в стандартный вывод. Вместе с перенаправлением `>` и `>>` помогает создавать текстовые файлы и дописывать строки.

## Синтаксис

```bash
echo [параметры] [текст]
```

## Основные параметры Bash

- `-n` — не добавлять перевод строки в конце вывода.
- `-e` — включить обработку управляющих последовательностей, например `\n`.
- `-E` — отключить интерпретацию обратных косых черт в Bash.

## Вывести текст в терминал

```bash
echo "Привет, Linux!"
```

Печатает заданную строку на экране.

## Создать файл с текстом

```bash
echo "Первая строка" > notes.txt
```

Создаёт `notes.txt`, если его нет, или **полностью заменяет содержимое** существующего файла. Оператор `>` выполняется оболочкой, а не самой командой `echo`.

## Добавить строку в конец файла

```bash
echo "Вторая строка" >> notes.txt
```

Добавляет строку в конец файла, не стирая предыдущие данные.

## Вывести значение переменной

```bash
echo "$HOME"
```

Показывает домашний каталог пользователя, сохранённый в переменной среды `HOME`.

## Вывести без перевода строки

```bash
echo -n "Введите имя: "
```

Печатает строку без завершающего перевода строки.

## Вывести две строки

```bash
echo -e "первая\nвторая"
```

В Bash с `-e` последовательность `\n` преобразуется в перевод строки.

## Особенности

`echo` встроена во многие оболочки, и детали обработки параметров и экранирования могут различаться. Для предсказуемого форматирования переменного текста чаще подходит `printf`.

Перед использованием `>` проверяй целевой путь, чтобы не затереть важный файл.

# wc — подсчёт строк, слов и символов

## Назначение

Команда `wc` подсчитывает строки, слова, байты и символы в файлах.

Используется для анализа объёма текстовых данных.

## Синтаксис

```bash
wc [параметры] [файл]
```

## Параметры

- `-l` — количество символов новой строки.
- `-w` — количество слов.
- `-c` — размер в байтах.
- `-m` — количество символов.
- `-L` — длина самой длинной строки в экранных колонках.

## Подсчёт строк

```bash
wc -l app.log
```

Показывает количество символов перевода строки. Если последняя строка не заканчивается переводом строки, результат может быть меньше числа визуально отображаемых строк.

## Подсчёт слов

```bash
wc -w article.txt
```

Показывает количество слов в документе.

## Размер файла в байтах

```bash
wc -c data.txt
```

Показывает количество байтов.

## Подсчёт символов

```bash
wc -m article.txt
```

Подсчитывает символы с учётом текущей локали.

## Подсчёт строк в нескольких файлах

```bash
wc -l first.txt second.txt
```

Выводит результат по каждому файлу и общий итог.

## Debian

Пакет: `coreutils`. -l считает символы перевода строки. Последняя строка без перевода строки не увеличивает этот счётчик.

```bash
wc -l -- app.log
```

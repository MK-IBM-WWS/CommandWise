
# ls — просмотр файлов и каталогов

## Назначение

Команда `ls` используется для просмотра содержимого каталогов Linux.

Позволяет узнать, какие файлы находятся в папке, посмотреть их размеры, права доступа и другую информацию.

## Синтаксис

```bash
ls [параметры] [путь]
```

Если путь не указан, выводится содержимое текущего каталога.

## Основные параметры

- `-l` — подробный список файлов.
- `-a` — показать скрытые файлы, включая `.` и `..`.
- `-h` — показывать размеры в удобных единицах (например, K, M, G).
- `-R` — рекурсивно показать содержимое подкаталогов.
- `-t` — сортировать по времени изменения.
- `-S` — сортировать по размеру файла.

## Примеры использования

### Просмотр текущего каталога

```bash
ls
```

Показывает файлы и папки текущего каталога.

### Просмотр скрытых файлов

```bash
ls -a
```

Показывает также файлы, имена которых начинаются с точки.

### Подробная информация

```bash
ls -l
```

Показывает права доступа, владельца, размер и другую информацию.

### Размеры файлов

```bash
ls -lh
```

Показывает подробную информацию с удобным отображением размеров.

### Просмотр определённого каталога

```bash
ls /var/log
```

Показывает содержимое каталога `/var/log`.

### Рекурсивный просмотр

```bash
ls -R
```

Показывает содержимое текущего каталога и его подкаталогов.

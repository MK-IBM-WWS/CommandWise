## Проверка командой перед защитой

1. Запустить прототип по README и пройти основной сценарий: новый чат → target → вопрос → ответ → источник → reload / история.
2. Проверить follow-up, остановку, no_context и демонстрационную ошибку; посмотреть мобильную ширину и клавиатуру.
3. После загрузки в GitHub открыть реальный workflow run, PR и commits; отметить checklist контрольной точки.
4. Добавить в этот документ фактические браузер, дату, результаты и найденные ограничения. Только после приёмки поставить тег checkpoint-1.

# Первая контрольная точка

## Основание

Приложенная презентация «Занятие 1. О курсе и SDD», слайд 12: показать тему и пользователя, основной сценарий, документацию, интерфейс/прототип, структуру репозитория и распределение работы. В Git должны быть README/запуск, SDD-документы, файлы интерфейса и история. Работающий RAG не требуется. Названия файлов на слайде 10 — пример, а не обязательный SDD-фреймворк.

## Соответствие материалов

| Требование | Где смотреть | Чем подтвердить |
| --- | --- | --- |
| Тема и пользователь | README, product | Объяснить задачу начинающего пользователя Linux |
| Основной сценарий | scenarios S01, demo-script | Пройти чат, ответ и источник |
| Документация | spec/product, spec/tech, AGENTS | Показать решения, API, способ проверки |
| Интерфейс/прототип | prototype/ | Открыть локально и показать mocks честно |
| Структура репозитория | repository-structure | Показать actual tree в GitHub |
| Распределение работы | team, plan | Каждый объясняет свою роль и путь запроса |
| README и запуск | README | Коллега запускает по инструкции |
| История изменений | Git commits/PR + CHANGE_HISTORY | Показать настоящую историю репозитория |

## Чек-лист команды перед показом

- [ ] Вписаны фактические имена, GitHub-логины и URL репозитория в team.
- [ ] Команда прочитала и приняла спецификации, target/стек и API.
- [ ] Материалы сохранены в вашем репозитории, нужные PR merged в main.
- [ ] `python3 scripts/check_docs.py` проходит на клоне.
- [ ] Прототип запускается, S01 и дополнительная ошибка/no_context показаны.
- [ ] У каждого есть доступ к репозиторию и понимание запуска.
- [ ] Настоящие commits/PR и роль каждого участника доступны для показа.
- [ ] При наличии remote workflow его фактический run проверен.
- [ ] Сохранён результат проверки и выбран тег checkpoint-1 после приёмки.
- [ ] Преподаватель имеет согласованный доступ; в закрытом репозитории это отдельно организует команда.

Пункты не отмечены автоматически: локально подготовленный архив не доказывает удалённую загрузку и участие всей команды. Backend, GPU, VPN, полный corpus и benchmark к этой точке не объявляются выполненными.

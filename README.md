# CommandWise

Локальный помощник по командам Linux. Встроенный корпус охватывает 50 команд для Debian, Fedora и Arch Linux. Эта сборка разворачивается на Debian 13 (Trixie), amd64.

## Установка и запуск

Нужны интернет, место для Docker-образов и около 9,5 ГБ для моделей, права root или sudo и NVIDIA GPU с драйвером, совместимым с CUDA 12.8. Для Tesla V100 используется проприетарная ветка R580. Перед установкой проверьте, что `nvidia-smi -L` показывает GPU. [Матрица совместимости NVIDIA](https://docs.nvidia.com/datacenter/tesla/drivers/latest/cuda-toolkit-driver-and-architecture-matrix.html)

Первый запуск из корня проекта:

```bash
./install-debian.sh
```

Установщик подготовит Docker и NVIDIA Container Toolkit, скачает модели, соберёт контейнеры и попросит задать логин и пароль администратора. Пароль вводится скрыто. Подойдёт любой непустой пароль без требований к минимальной длине или набору символов. Технический предел — 4096 байт. Для регистрации обычных пользователей действует прежнее правило от 8 символов до 72 байт.

Сайт открывается на [127.0.0.1:8080](http://127.0.0.1:8080), панель администратора доступна по адресу [127.0.0.1:8080/admin](http://127.0.0.1:8080/admin). Повторный запуск:

```bash
./start-debian.sh
```

Адрес и порт задаются через `CW_BIND` и `CW_PORT` в `.commandwise/compose.env`. При доступе через HTTPS-прокси оставьте привязку к локальному адресу, укажите внешний origin в `PUBLIC_ORIGIN` и установите `COOKIE_SECURE=true`. Прокси должен передавать исходный Host и пропускать поток SSE.

## Обновление действующей установки

Скопируйте файлы архива в текущий каталог проекта, сохранив `.commandwise` и тома Compose. Затем пересоберите сервисы:

```bash
./commandwise.sh build backend frontend search && ./start-debian.sh
```

Модели используются повторно. Существующий пароль администратора продолжает работать. Сменить его можно через настройки профиля.

## Работа с приложением

- Нажатие на никнейм открывает настройки. Для изменения никнейма или пароля нужен текущий пароль. Никнейм используется для входа.
- На аккаунт доступно до 10 чатов. В каждом аккаунте одновременно генерируется один ответ, остальные ждут. Два разных аккаунта могут генерировать одновременно.
- Во вкладке «Пользователи» администратор может менять никнеймы, сбрасывать пароли и удалять другие аккаунты вместе с чатами. При сбросе пароля активные сессии пользователя завершаются.
- Во вкладке «Корпус» можно публиковать Markdown в UTF-8 размером до 512 КиБ. Разделы обозначаются заголовками второго или третьего уровня. Чтобы открыть источник ответа, нажмите его номер под сообщением.

Для генерации используется Qwen3-14B Q4_K_M в llama.cpp с двумя слотами по 4096 токенов. Поиск выполняют BM25 и multilingual-e5-small ONNX на CPU. [Qwen3-14B GGUF](https://huggingface.co/Qwen/Qwen3-14B-GGUF) · [multilingual-e5-small](https://huggingface.co/intfloat/multilingual-e5-small)

## Диагностика

```bash
./commandwise.sh ps -a
./commandwise.sh logs --tail=100 backend search llm
```

Если PostgreSQL сообщает `password authentication failed for user "commandwise"`, запуск проверяет и при штатной конфигурации синхронизирует служебный пароль из `.commandwise/compose.env`. Такой же ремонт можно выполнить через `./repair-db-auth.sh`. Служебный пароль PostgreSQL отличается от пароля веб-администратора.

Если `search` не готов, проверьте его журнал. Встроенный индекс собирается из документов, перечисленных в `corpus/manifest.json`. При отсутствии указанного файла восстановите его из архива и пересоберите Search через `./commandwise.sh build search`. В журнал автоматически попадают предупреждения о лишних документах и ход пересборки индекса.

## Удаление

```bash
./uninstall.sh
```

Команда удаляет контейнеры и сеть, сохраняя аккаунты, чаты, документы, настройки и модели. Для полного удаления данных приложения выполните:

```bash
./uninstall.sh --purge
```

Этот режим удаляет тома с аккаунтами, чатами и документами, каталог `.commandwise` с моделями и настройками и локально собранные образы. Исходники, Docker и системные пакеты остаются на сервере.

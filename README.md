# Linux Command RAG

Русскоязычный помощник по документации команд Linux с поиском BM25 и ответами локальной LLM.

## Тема и пользователь

**Тема:** поиск и объяснение команд Linux по проверенному корпусу документации с учётом дистрибутива и версии.

**Пользователь:** студент или начинающий администратор, которому нужно подобрать команду, понять параметры и проверить ответ по источнику.

Пример задачи: «Как найти обычные файлы размером больше 100 МиБ в Debian?» Пользователь выбирает систему, задаёт вопрос, получает объяснение и открывает использованные фрагменты документации.

## Что готово в этом комплекте

|Материал|Статус|
|-|-|
|Продуктовые и технические спецификации|Подготовлены для обсуждения и принятия командой|
|Контракты Go API и BM25 API|Проект OpenAPI 3.0.3; реализации API в комплекте нет|
|Интерфейс|Автономный демонстрационный HTML-прототип|
|Backend, BM25, база, LLM, production React SPA|Планируются; исходники реализации здесь отсутствуют|
|Корпус и итоговый benchmark|Описаны формат и методика; реальный корпус и результаты ещё не представлены|



## Запуск прототипа

Открыть `prototype/index.html` в современном браузере. Внешние зависимости не требуются; данные локальные и демонстрационные.



## Архитектура рабочей версии

|Сервис|Технология|Назначение|
|-|-|-|
|frontend|React + TypeScript + Vite; Nginx|Чат, история, источники, потоковый вывод|
|backend|Go, net/http, pgx/v5, PostgreSQL|Сессии, чаты, поиск, prompt, вызов модели, SSE|
|search|Python 3.13, FastAPI, rank-bm25, NLTK|Подготовленный корпус, BM25, фильтрация target|
|llm|Ollama, первоначально Qwen3.5-27B|Локальная генерация на V100|
|postgres|PostgreSQL|Сессии, история, snapshots источников|

Путь: браузер → Nginx → Go → BM25 → Go → LLM → Go → браузер. Пять постоянных контейнеров; индексатор и миграции — временные задания.

Приложение планируется на принадлежащем команде сервере Debian 13, CPU 12600K, RAM 96 ГБ, Tesla V100 16 ГБ.
